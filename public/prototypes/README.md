# 后宫 · OiiOii 风格 HTML 原型

打开 `hougong-oii.html` 即可预览；CSS、JavaScript、图标和图片全部内嵌，无需安装依赖或联网。

参考：https://www.oiioii.tv/zh/

采用深色点阵背景、粉色主操作、大创作输入区和左侧工作空间导航。品牌与视觉资源复用本仓库资源。

## 视图与路由

原型是一份单文件里的多个视图，靠 hash 切换：

| hash | 视图 | 对应正式站 |
| --- | --- | --- |
| `#/` | 首页 | `/` |
| `#/chat/<会话>` | 创作对话页 | `/create` |
| `#/skills` | 技能页 | `/effects` |
| `#/assets` | 资产页 | `/assets` |
| `#/tv` | TV 频道 | 频道页（待建） |
| `#/canvas` | 画布预览 | `/canvas` |
| `#/canvases` | 我的画布 | `/canvases` |

侧栏**不再挂画布相关的两个入口**（编辑器「画布」和列表「我的画布」都撤下，对应
`canvasFeatureEnabled()` 生产为关），但 `#/canvas`、`#/canvases` 两条路由都留着 ——
直接开链接仍然能进，入口恢复只差一个开关。

- **所有视图共用同一层背景**：点阵背景挂在 `body` 级（`#dot-background`），首页 / 对话页 / 技能 /
  资产 / TV 都用它，鼠标经过的点阵高亮（`dot-trail`）各处都生效 —— 风格只维护一处，不要各画一份。
- 首页「发送」→ `enterChat()`：把草稿合成一条用户气泡，跳到对话页。
- 对话页演示三件事：
  - **内容滚动**：贴底时跟最新，用户往上翻就不打断，改出「回到最新」。
    （生成中的进度刷新走 `renderChat()`，不会再把人拽回底部。）
  - **思考行**：角色名 + 转圈 + 用时秒表 + 可展开的思考文本，收尾后变成一行「用时 N 秒」。
  - **生成等待进度**：任务卡「排队中 → 生成中(进度条 + %) → 已完成(产物 + 查看大图)」。

## 首页：输入框下面的技能快捷片

位置和参考站一致 —— **紧贴输入框正下方**（不是另起一个带标题的区块），实测间距 12px：

```
[ 输入框 ]
 上排 5 张：脱衣 / 脱衣视频 / 掀衣视频 / 裸体姿势视频 / 性感动作
 下排 3 张：展示胸部 / 电臀舞 / 乳房按摩  +  [→]   ← 第 9 格固定是跳转 icon，去技能页
```

- 只铺 `QUICK_COUNT = 8` 个（`TOOLS.slice(0, 8)`），第 9 格是跳转格；想要别的数量改这一个常量。
- **上排铺满、下排居中**：容器用的是 flex + `justify-content: center`（**不是 grid** ——
  grid 做不到「少一张的那行居中」）。卡片宽度 `calc((100% - 间隙) / N)`，实测两行中心线对齐。
  断点：>800px 每行 5 张、≤800px 4 张、≤600px 2 张。
- **跳转格不带按钮框**：没有边框、没有底色、里面也没有圆圈，就是一个箭头（hover 变白）。
- **跳转格不占一整格宽**：`#tool-grid .mode-jump { width: 48px }`。原来它和其它卡一样宽（~154px），
  却只画 16px 的箭头 —— 既离上一张远，右边又多出一片空白，看起来「左右留边不一样」。
  收窄后箭头紧贴最后一张（8px，和卡片间距一致），整行左右留边也就相等（实测 133 / 134）。
- **每个技能自带色底**：`TOOLS[].tint` 一个色值 → 底色 = 该色 13% 叠在 `#141414`、描边 = 该色 30%
  （hover 22% / 62%），用 `color-mix()` 算，不写死四套。缺 `tint` 回落中性白。
  图标是 30×30 的小方块（参考站那排也是方块，不是 16:9 缩略图）。
- **鼠标划上去浮一张卡**（封面 + 名称 + 描述），贴在卡片正上方；描述取后端目录的 `summary`。
- 点一张 = 选中该技能（输入框上方出现技能胶囊，配了模板的才多一个「模板」）。

## 只照搬「风格」，不照搬「入口」

风格（点阵背景、动效、卡片网格、输入区几何）取自参考站；**入口一律以本机现状为准**，
参考站有、本机没有的一律不画：

| 位置 | 本机实际（原型照此实现） |
| --- | --- |
| 侧栏 | 首页 · 工作室 · 技能 · 资产 · TV 频道 · 我的发布 |
| 侧栏 · 角色资产 | `FEATURES.characterAssets = false`，当前不出现入口（页面与接口都还在） |
| 侧栏 · 画布 | 编辑器与「我的画布」两个入口都撤下（`canvasFeatureEnabled()` 生产为关），两条路由保留 |
| 顶栏 | 面包屑「创作 / 首页」+ 发布作品 + 登录 / 注册 |
| 输入器 · 常驻 | 图片/视频切换 · 上传参考图（＋） · 模型 · 自定义参数 · 发送 |
| 输入器 · 模板 | **不常驻**。只在从工具入口选中某个工具、且该工具自己配了模板时才出现 |
| 首页技能区 | 卡片来自后端目录 `GET /hougong/tools`，点一张 = 选中该技能 |
| TV 频道 | 站内作品频道，正式接入后读后端 feed；原型用本地占位封面 |
| 技能页 | 标题 + 分类页签（图片 / 视频）+ 三列卡片（封面 / 标题 / 描述 / 试试看） |
| 资产页 | 默认**空库**，只有「生成 / 上传 / 批量上传」三个入口 |

参考站特有的「创作行业」页签、短漫剧剧本面板、语言切换、技能 / 风格 / 资产工具条、
「自由画布 / 图片创作 / 资产 / 我的发布」入口卡、双击进入画布等，本机都不存在，已从原型移除。
参考站技能页的「创建我的 Skill」、资产页的「演员库 / 回收站」，本机也没有对应能力，同样不画。

## 封面比例：三类卡各有各的屏向

| 位置 | 比例 | 为什么 |
| --- | --- | --- |
| 探索灵感（首页 feed） | 竖屏 `3 / 4` | 封面墙，竖屏密排更好看 |
| 技能页 | 竖屏 `3 / 4` | 和探索灵感同一套，一屏能放 5 张 |
| 资产 · 演员库 | 横屏 `4 / 3` | 和上面两类错开 —— 一眼能分清「这是人」还是「这是作品」 |

首页输入框下面那排「技能快捷片」是紧凑入口条（`16 / 9` 小图 + 名称），**不是**上面说的技能页卡片；
它是快捷入口，比例不跟着技能页走。

## 演员库：一个实体，两个来源

「资产 → 演员库」是本机**已有**的能力（`app/pages/characters/*`、`/hougong/characters`、
`CharacterItem`），原先只是被 `FEATURES.characterAssets` 藏起来了 —— 不是新概念，别再造一套。

字段口径沿用 `CharacterItem`：`name` / `alias` / `age` / `tagline` / `traits` / `coverUrl` / `workCount`，
只多两个：`scope`（`mine` | `public`）与 `sourceId`（从公共库复制来的溯源）。

| 规则 | 说明 |
| --- | --- |
| 一个实体 | 公共库和我的库**同一张表、同一套卡片**，只差一个「来源」字段；不做两套 |
| 公共库只读 | 运营维护，前台不能改（后端拒写） |
| 我的库默认私有 | 自建演员只有自己能用；要进公共库走「⋯ → 申请公开」，运营审核（`status: reviewing`） |
| 复制到我的 | 想改公共的 → fork 一份副本（带 `sourceId`），改副本，公共那条不动；fork 完自动切到「我的」 |
| 配额 | 我的库有上限（`ACTOR_QUOTA`，原型 50），公共库不计 |
| 引用要冻结 | 任务提交时存 `characterId` + **快照**。公共演员以后改了下架了，都不影响已产出的作品 |

UI 上「我的 / 公共」用**分段控件**而不是再加一层页签 —— 它们是同一件事的两个来源，不是两个功能；
两边的卡片样式只有一套，靠右上角角标（私有 / 审核中 / 公共）区分。

## 资产库：产物不自动进库

这是**有意为之的交互约定**，不是没做完：

- 库默认是空的，页面不会去「加载」任何生成结果；
- 产物卡上必须由用户点「加入资产」，那一张才会写进库；点过之后按钮变「已加入资产」且不可重复加入；
- 资产页的「上传 / 批量上传」同样是用户主动动作。

对应到正式站：`/hougong/assets` 只列用户显式收进来的资产，生成完成不隐式写库。

## 数据与接入边界

这是独立交互原型：示例作品明确标注；生成只展示参数摘要，不调用后端、不上传、不计费。

`TOOLS` 的字段口径与 `app/composables/useToolCatalog.ts` 的 `ToolItem` 对齐
（`code` / `name` / `category` / `input` / `badge` / `summary` / `templates`，另加一个 `tint` 色值），条目值取自本地后端实测；
`cover` 是本地占位图，不是这些工具的真实效果图。正式接入时由 `useToolCatalog` 直接驱动，
**不要**复制这份常量；调用后端继续通过 `useHougongApi`，模型候选与报价继续由 `useModelCatalog` 提供。

「探索灵感」对应正式站首页登录后才渲染的 explore 区块，原型里的封面仅用于本地视觉对照。

原有 Nuxt 页面、接口、登录与功能开关均未改动。

## 本地预览

在仓库运行 `python3 -m http.server 4178 --bind 127.0.0.1 --directory public/prototypes`，
打开 http://127.0.0.1:4178/hougong-oii.html 。Nuxt 启动时也可直接访问 `/prototypes/hougong-oii.html`。
