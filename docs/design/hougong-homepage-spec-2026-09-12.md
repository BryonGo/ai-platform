日期：2026-09-12。

状态：产品重新定义后的首页设计讨论稿。已确认要求与建议参数分开记录；本文不代表页面已实现，也不授权开始修改页面代码。

后续决策覆盖：用户已确定前台仅选择模型，展示后台提供的介绍、能力和费用，不展示平台／ComfyUI／云端 API 分类。下文旧平台选择描述以此为准。首页与对话页的前后端实施范围见 [Nuxt / Go 编码交接](../HANDOFF-HOME-CHAT-2026-09-12.md)。

## 1. 文档范围与优先级

本文件整理首页的信息结构、视觉方向、操作状态及本轮效果图批注。创作详情、工具详情、完整发布流程、资产详情和专业画布另行设计。

发生冲突时依次采用：用户最新批注 > 本文已确认要求 > 最新效果图 > 历史设计记录。效果图中的尺寸、文字、价格、模型名称和示例内容不构成真实配置或接口能力证明。

本次是整体重新设计前台体验。后续实施应复用已有功能、接口和工作流，通过最小生成管线逐步接入；“最小改动”不限制新页面只能在旧布局上挪菜单。

旧文档中的“首页保持原版不动”、角色故事中心定位、只保留三个主入口等，不再约束本次首页设计。此前未经用户要求产生的代码改动，不作为设计依据。

## 2. 产品与首页职责

后宫面向个人创作者，支持通过对话生产图片和视频，通过封装工具完成明确的处理任务，并积累资产、主动发布作品。专业用户后续使用独立画布。

首页应让用户立即发起创作，同时能够找到工具、继续最近创作、浏览作品。整体参考即梦式创作者工作空间；工具组织参考 All Effects 的效果入口方式。角色是可复用的生产资产，不是开始创作的必填步骤。

## 4. 首页信息结构

主内容自上而下：

1. 顶栏：当前位置、发布入口、账户状态；登录后显示余额、通知与头像菜单。
2. 创作区：标题、人物背景、输入框外的图片／视频创作切换、对话输入框。
3. 全部工具：有限数量的常用工具预览，以及进入完整工具页的入口。
4. 继续创作：最近会话／结果入口、必要的任务状态。
5. 探索灵感：分类切换与无限滚动作品流。

首页自身承担创作入口，不使用大型营销落地页替代操作区域。增加人物展示空间时，仍应让常见桌面首屏可见模式切换和可操作的输入区。

### 4.1 左侧导航

| 分区 | 内容 | 状态与要求 |
| --- | --- | --- |
| 品牌与开始 | 后宫、新建创作 | 保留彩色品牌标识与醒目的主操作 |
| 主要入口 | 创作、全部工具、画布、探索、我的资产 | 画布独立，不属于输入区的对话标签；当前为后续功能 |
| 资产子项 | 图片、视频、角色资产、我的发布 | 点击目标为整行，图标、文字与行背景共同表示状态 |
| 历史 | 最近会话 | 可找到并继续已有创作 |
| 底部工具 | 模型、通知、设置 | 次要入口，不与主要创作操作争夺注意力 |
| 固定链接 | 隐私政策、用户协议等 | 固定于侧栏底部，与无限作品流分离；实际协议内容与地址另行确定 |

侧栏使用区别于主页面的灰色底色；当前项使用更深的整行背景，不能只有文字或图标变色。整行高亮应覆盖条目可点击宽度，保留统一内边距和圆角。彩色图标采用一致线宽与大小，同一功能保持同一颜色。

建议将侧栏分成可滚动导航区和始终可达的底部区，避免低高度窗口下历史会话挤掉协议链接。黑底主题若另行采用，则整行状态改用灰底，始终保证对比；本轮主方案为灰色侧栏。

### 4.2 人物背景与上方留白

- 沿用用户提供的妲己人物身份与红裙、白色尾部视觉；本次按用户最新称呼采用九尾方向，历史三尾文档不强制覆盖最新要求。
- 人物位于创作区右侧，与背景融合，左侧与下方渐隐，避免干扰文字和控件。
- 增加标题、模式切换与输入框上方的空间，优先展示人物面部、上身和尾部轮廓；不把背景仅剩一张头像。
- 不通过降低输入内容对比来换取人物可见性；人物不得遮挡头像菜单、生成按钮和平台选择。
- 效果图并未准确验证尾巴数量。后续正式人物素材需要另行确认，不把这张局部背景当作定稿角色母版。

## 5. 创作区与交互

### 5.1 模式位置

“图片创作 / 视频创作”位于输入框外上方，配图片／视频图标并明确区分当前模式。输入框内部不再重复放同一切换。画布只在独立导航入口出现。

切换模式不自动生成、不自动扣费。建议保留可兼容的草稿内容，对不兼容素材明确提示或取消引用；具体转换规则在创作页设计中补齐。

### 5.2 输入与上传

- 输入文字表达需求；通过 `@` 引用素材或可用预设，选中后在文本内显示引用标记。
- 保留 `@` 入口，去掉重复的图片、视频、角色资产附件按钮和圆形加号。
- 当所选模式与模型允许参考图时，在输入框内部显示“上传图片”区域，使用上传图标与明确可点击范围。
- 当前 ComfyUI 图片管线为文生图，不支持图生图时隐藏上传框；此限制不能推广为所有 ComfyUI 工作流的限制。首帧视频按其真实能力显示上传区。
- `@` 选择器同样遵守能力约束；不能在已隐藏上传框的模型下，通过引用图片绕过限制。纯文生图可以支持的文字类预设需按实际能力确定。
- 平台、模型、画幅等参数采用熟悉的图标与必要文字组合，避免一排无图标的长文本按钮。

### 5.3 平台与费用

用户选择执行平台，系统不暗中替换。模型选项、上传区和可用参数随实际能力更新。生成前显示费用，无法报价时不编造价格。

输入框底部保留平台／模型、必要参数、费用与生成操作；图片／视频切换已移到框外。具体初始平台与模型如何保留用户偏好，仍需在创作流程中细化。

### 5.4 鎏光与交互状态

输入框需要互动鎏光效果，以细边框与小范围高光体现材质，不使用厚重霓虹。

建议状态：默认柔和描边；悬停时局部高光响应指针；输入聚焦时边缘缓慢流动；失焦后收束。用户偏好减少动态效果时使用静态描边。

`@` 输入或按钮可打开可搜索的引用面板。建议支持方向键选择、Enter 确认、Esc 关闭，手机端提供等价触摸选择。这些是待实现交互，不是现有能力验收结论。

## 6. 工具、结果卡片与媒体规格

### 6.1 卡片视觉

- 全局减少媒体规格，只使用横版 `16:9` 和竖版 `9:16` 两种主要展示框；头像、上传控件等不属于内容媒体框。
- 图片／视频结果的实际输出比例与列表展示框分开处理，不改变原始文件比例。
- 同一展示组使用一致的媒体框、页脚高度与间距，不使用任意高度混排造成杂乱。
- 单个卡片和页脚使用明显浅于黑色页面的灰色底色，完整轮廓清晰可辨；圆角比第一版更大。
- “热门”“最新”标签放在图片右上角。效果图示例不代表真实热度；发布时使用实际标签数据。
- 不为填满首页而将尚不可用的工具显示成可执行功能。首页工具清单与上线状态需在实施前核对。

当前效果图展示工具：文生图、图片编辑、首帧生视频、图片换脸、视频换脸、背景替换、服饰替换、高清修复、动作特效、运镜特效。它们是功能覆盖讨论清单，不构成全部已实现或全部首期上线的承诺。

### 6.2 横竖图展示规则

| 场景 | 规则 |
| --- | --- |
| 工具预览 | 建议统一横版 16:9，固定卡片尺寸 |
| 最近创作 | 同组保持统一框；不同原始比例通过适配展示，不拉伸 |
| 探索作品 | 竖版优先按手机 9:16 展示；横版内容采用统一横版组，避免任意尺寸拼贴 |
| 列表封面 | 可以围绕主体裁切，必要时使用单独封面；不能把裁切后的封面视为完整产物 |
| 完整预览 | 保留原始宽高比，完整显示；留边优先于拉伸或裁掉内容 |

横版与竖版在探索流中具体如何分组、是否提供比例筛选，仍待细化；已确认的是控制尺寸种类与展示整齐，而非确定一种瀑布流算法。

### 6.3 悬停、放大与蒙版

- 桌面鼠标悬停时出现清晰边框，图片在卡片内部适度放大，外部卡片尺寸不变，不推挤相邻内容。
- 底部操作蒙版渐显，可放预览、继续创作、创作同款或发布等与当前卡片相关的动作，不一律堆满所有操作。
- 原图／效果对比使用同一画面坐标的两层图片与可拖动蒙版。不能把两张缩小肖像并排冒充滑动对比。
- 手机没有悬停；需要可见的触摸入口或明确的点击操作，关键功能不能依赖 hover 才能发现。
- 建议参数为内部缩放约 1.04 倍、过渡约 180ms；这些是试验初值，尚未定稿。

## 7. 探索灵感与无限滚动

已确认：探索灵感是首页下方的无限滚动作品流。全部工具与继续创作仍为上方有限区域，不随信息流重复追加。

建议实现体验：

- 滚动接近列表末尾时请求下一批，仅追加新作品，不替换已有内容。
- 初次加载、继续加载、加载失败、分类为空和已无更多作品有不同状态；无限滚动不等于永远显示加载动画。
- 图片加载前预留尺寸，避免内容跳动；标签与页脚不改变卡片外框尺寸。
- 切换分类时重置相应列表与分页状态；从作品详情返回时尽量恢复原滚动位置。
- 请求失败保留当前结果，允许重试；避免重复请求和重复作品。
- 键盘和触摸用户可到达加载／重试入口；可提供加载更多作为自动加载的补充。

隐私政策、用户协议等不得放在信息流末尾。桌面端放侧栏底部固定区；移动端须放在导航抽屉或账户中的稳定入口，具体移动布局另行出图，不照搬桌面多栏。

## 8. 账户、登录与发布入口

### 8.1 已登录

顶栏头像带下拉指示。点击展开菜单，点击外部或 Esc 关闭。当前设计菜单包含个人中心、我的发布、钱包与账单、偏好设置、退出登录；最终名称与可用页面需核对。

### 8.2 未登录

需要未登录弹窗。未登录顶栏显示登录／注册入口，不显示伪造的用户余额和头像状态。

当前交互建议：浏览首页与探索无需先登录；点击生成或发布时打开登录弹窗。登录窗口可关闭，关闭后保留草稿。成功登录后回到生成／费用确认状态，不自动执行付费任务。

效果图用邮箱／密码表达登录结构；真实登录方式、注册和密码找回能力以实际系统与后续确认方案为准，不因图中出现就新增功能。

### 8.3 发布

首页提供发布作品与我的发布入口，探索区显示主动发布的作品。私人生成结果不会自动公开；发布表单与“创作同款”允许复用的信息范围另行细化。

已确认：黑色主背景、灰色侧栏、明显更浅的灰色卡片、彩色图标、更大圆角、精致橘色主按钮、局部渐变材质、人物背景与输入框鎏光。

以下只用于后续设计试验，不能当作已确认设计 token：

| 页面底色 | #101114 |
| 侧栏底色 | #25272C |
| 侧栏整行选中底色 | #141518，明显深于侧栏 |
| 卡片／页脚 | #30333A / #363940 |

## 11. 后续设计检查表

- 图片／视频创作切换在框外上方，框内无重复切换；画布为独立入口。
- 人物展示空间比 v3 增加，且不妨碍输入和参数操作。
- 侧栏灰底与条目深黑整行状态区分清楚，底部协议链接随信息流滚动仍可达。
- 上传框、`@` 与所选模型能力一致，没有多余的加号和附件按钮。
- 卡片圆角、背景、页脚、标签统一；手机竖版真正采用 9:16，不是近似 3:4。
- 悬停仅缩放内部图像，手机有等价操作；原图／效果对比显示同一坐标画面。
- 探索支持连续加载及失败／结束状态，协议不放信息流底部。
- 未登录和已登录分别设计，草稿与费用确认状态不因登录而丢失。

尚需细化：增加人物留白的确切高度、移动端布局、探索横竖分组方式、首期工具可用性、登录方式、正式图标／人物资源和最终视觉参数。以上不阻碍先确定本文首页方向；开始改页面仍需用户明确要求。
