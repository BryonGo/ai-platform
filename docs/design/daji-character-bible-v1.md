## 本轮补充规范

### 外观锚点

- 保持参考脸型，不因强化妖艳而改变为另一张脸；成熟成年比例、细长眼型、微挑眼尾。
- 深棕近黑长发，半束发，保留脸侧碎发；银白花枝发饰置于头顶后侧，与参考一致。
- 琥珀棕瞳，细长上挑眼线，克制的红色眼影、朱红唇色。保留真实皮肤层次。
- 白狐耳，内侧淡粉；三条尾巴为象牙白，暖光下可带淡粉反射，不染成红色。

### 性格与表情

聪明、从容、善于引导，带一点狡黠。妖艳通过直视、眼尾、唇色与含蓄笑意表达；基础站姿保持自然，避免每个功能场景都重复夸张表情。

### 服装与饰品

- 朱红丝缎细肩带裙，包裹式腰线，单侧开衩、前短后长的不对称下摆；胸部与骨盆以不透明面料覆盖。
- 减少长披帛、大袖与多层裙撑，突出红裙与白尾的清晰轮廓。
- 小型琥珀金腰扣，作为次要细节，不将暂定 Logo 永久写入服装结构。
- 双踝采用细金链，每侧三枚小铃铛；铃铛位置及数量后续资产保持一致。
- 人形赤足，脚趾、脚踝完整可见；基础设定双脚自然落地。

### 三尾结构（当前有效）

- 恰好三条，从后腰下方同一解剖区域分叉展开，避免从肩背或手臂生长。
- 常态一条向上弯、两条向侧下方收拢，轮廓不对称，尾尖逐条可辨，不采用巨大对称扇形。
- 正面以尾尖和前后遮挡表现深度；三尾属于固定角色设定，不能在资产中随机增减。
- 狐灵动物形态延续三尾身份：完整成年小白狐的体态，三尾自然叠拢，保留小铃铛项圈。
- 小尺寸功能插画可通过裁切简化尾部显示，不通过修改角色尾巴总数简化。

## 配色职责

品牌界面：石墨黑 + Amber；角色：朱红裙 + 象牙白狐尾 + 深发；金色只用于少量配饰。人物红色不自动替代界面 Amber 主色。

## 使用与后续

1. 先确认三尾正面全身候选，再审核侧面、背面，重点核对脸型、三尾数目、衣服结构与铃铛。
2. 再制作人形欢迎横幅、创作引导，以及小白狐加载、空状态资产。
3. 最后以真实资产验证创作首页与角色详情页。当前不开始整站编码。

现有图像均为概念稿，不视为已完成的矢量 Logo 或可直接批量投产的角色模型。
