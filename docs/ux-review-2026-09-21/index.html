原型说明
PRODUCT & EXPERIENCE REVIEW

让第一次创作，有清楚的下一步。

产品定位

面向普通用户的 AI 图片与视频创作社区

用户提出想法，AI 创作助手带着完成作品，用户决定是否分享。把“描述 → 确认 → 生成 → 修改 → 发布”串成一条连续路径。

01 / ONBOARDING

登录是接续，而不是重来

  • 点注册直接到注册，弹窗与独立页面规则一致。
  • 认证前后保留描述、素材、模板与所在步骤。
  • 成功后回到确认页，不自动触发付费生成。
  • 忘记密码、协议链接必须有真实去向。
02 / CREATION

先教写什么，再谈模型

  • 图片：主体、场景、画风；参考图可选。
  • 视频：按能力区分文字生成与起始图片生成。
  • 比例、数量、时长与费用在主界面可见。
  • 首页“下一步”，确认页“生成 · X 积分”。
03 / EFFECTS

效果模板变成四步引导

  • 选效果 → 准备素材 → 确认 → 查看作品。
  • 卡片说明需要什么、能得到什么。
  • 前进缺项就地提示，返回不清空输入。
  • 加载失败、暂无效果、搜索无结果分别处理。
04 / AGENT

工作过程可见、可理解

  • 生成前展示可编辑的本次任务摘要。
  • 进度来自真实状态，不伪造百分比或思考过程。
  • 刷新状态、加载作品、重新生成是不同动作。
  • 创意辅助须独立接入，不把讨论误作生成。
05 / UGC

创作完成，就是分享入口

  • 结果直接提供修改、下载、发布。
  • 作品默认私密，主动确认后才公开。
  • 公开字段预览，提示词共享单独选择。
  • 作者与来源可见，创作同款尊重复用权限。
06 / TRUST

每个按钮都有可信的结果

  • 点击有状态，禁用有原因，错误保留输入。
  • 费用未知不写兜底价格，退款依真实状态。
  • 删除热区、键盘焦点与减少动效均可用。
  • 不宣称未经确认的无存储或公开访问能力。

建议实施顺序

阶段重点修改验收结果
P0 · 消除断点认证模式、草稿接续、提交语义、缺图校验、准确费用与状态不丢输入、不误提交、不作虚假承诺
P1 · 完整旅程创作输入框、效果四步、任务反馈、结果直接发布无需理解模型，独立完成第一件作品
P2 · 社区与助手公开发现、授权同款、真实分享链接、创意辅助形成从欣赏到创作再到分享的循环
