## 2. 当前技术形态

目前项目是一个**前端项目，同时保留 Nuxt 全栈扩展能力**，但暂时还没有实现业务后端。

当前已经具备：

- Nuxt 4 前端应用
- Vue 页面与组件结构
- Nuxt UI 组件库
- Tailwind CSS 样式能力
- TypeScript
- ESLint 与 Prettier
- Nuxt SSR/SSG 基础能力
- Nuxt Server API 后续扩展能力

当前还没有实现：

- 用户注册、登录和权限系统
- 数据库和数据模型
- AI 模型调用接口
- 文件上传和对象存储
- 任务队列和异步任务管理
- 计费、积分或用量系统
- ComfyUI 工作流调用
- 生产环境部署配置

## 6. ComfyUI 说明

当前项目中**没有集成 ComfyUI**，也没有 ComfyUI API 调用代码。

如果后续需要支持 AI 绘图、图生图、工作流编排，可以将 ComfyUI 作为独立的 AI 执行服务：

```text
浏览器
  ↓
Nuxt 前端
  ↓
Nuxt Server API / 独立后端服务
  ↓
ComfyUI API
  ↓
模型推理与任务结果
```

推荐不要让浏览器直接访问 ComfyUI，而是通过服务端代理或后端任务服务访问。这样可以统一处理：

- ComfyUI 地址和鉴权
- 工作流 JSON 管理
- 任务提交、排队和状态轮询
- WebSocket 进度推送
- 结果图片保存
- 用户权限和用量统计
- 错误重试与超时

## 7. 后续可能的两种架构

### 方案 A：Nuxt 一体化

```text
Nuxt 页面
  + Nuxt Server API
  + 数据库
  + 对象存储
  + ComfyUI
```

适合早期验证和中小规模项目，开发速度较快，部署结构简单。

### 方案 B：Nuxt + 独立后端

```text
Nuxt 前端
  ↓
独立后端 API
  ├─ 用户与权限
  ├─ 数据库
  ├─ 任务队列
  ├─ 文件存储
  └─ ComfyUI / 其他模型服务
```

适合后续多模型接入、复杂任务队列、多人协作和规模化部署。
