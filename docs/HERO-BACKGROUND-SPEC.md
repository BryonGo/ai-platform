# 首页 hero 背景素材规格

适用范围：`app/pages/index.vue` 里 `.hero-art` 那个背景位（首页顶部「今天，想创作什么？」右侧）。
本文回答两件事：**出图该做多大、构图怎么放**，以及**出图方只能给 JPEG 时怎么转成带 alpha 的素材**。

## 1. 显示尺寸（浏览器实测）

首页内容列上限 1400px（宽屏居中），hero 高 344px（移动端 364px）；背景位宽度 = `min(54%, 820px)`：

| 视口 | 背景位渲染尺寸 | 比例 |
| --- | --- | --- |
| 2560×1440 | 756 × 354 | 2.14 : 1 |
| 1920×1080 | 756 × 354 | 2.14 : 1 |
| 1440×900 | 619 × 354 | 1.75 : 1 |
| 1280×800 | 548 × 354 | 1.55 : 1 |
| 390×844（手机） | 210 × 374 | 0.56 : 1 |

素材按 `object-fit: cover`、`object-position: 58% 0%`（顶部锚定）铺进这个框。

## 2. 出图尺寸

- **画布比例按 2.13:1**（与 2.14:1 的显示框匹配，所以桌面端整张图都能显示，不浪费）。
- 生产提交尺寸：**2048 × 960**（当前素材 `daji-hero-2048x960.jpg` 即此规格）。
- 上线素材再压到 **1512 × 708**（= 最大显示宽 756px 的 2 倍视网膜）。再大对屏幕没有意义，
  只会让首屏资源变胖；转换脚本默认就按 1512 输出。

## 3. 构图安全区（按 2048×960 的像素坐标）

```
x:  0        696      918        1434     2048
    ├─────────┼────────┼──────────┼────────┤
y=0 │ 左侧渐隐   │ 手机可见条 │  主视觉可用  │
    │ (0–34%)    │(45–71%)   │  (71–100%) │
y=288│═══════════╧═══════════╧════════════│ 30%
    │      标题文字带（y 16–34%）          │
y=346│──────────────────────────────────────│ 36%
    │      输入框覆盖区（y 36–100%）        │
y=960│                                      │
```

1. **主视觉（脸/核心元素）放 x 1024–1434（50–70%）、y 0–288（上 30%）**——这是同时满足
   「电脑完整显示」与「手机窄条也能看到」的位置（手机上只露 x 918–1458 这一段）。
2. **左侧 0–696 只放氛围**（云、光、雾）：横向遮罩会把这一带渐隐掉。
3. **下方 y 346–960 被输入框覆盖**，且从 y≈384 起向下渐隐：这里只能放很暗的氛围，
   不能有脸、手、文字、亮点。

## 4. JPEG → 带 alpha 的素材

出图工具只能给 JPEG（无透明通道），但页面画布是 `#101114` 深色、右上还压着一团琥珀色光晕，
满幅方图会露出一块比页面亮的矩形。转法见 `scripts/hero-alpha.py`：

```bash
# 只有 WebP 进 public/（页面引用它）；源图与 PNG 交付件放 docs/ 下，不打进产物
python3 scripts/hero-alpha.py docs/design/artwork/daji-hero-2048x960.jpg \
  --out-webp public/images/daji-hero-alpha.webp \
  --out-png  docs/design/artwork/daji-hero-alpha.png
```

脚本做三件事：

1. **亮度键控**：`alpha = smoothstep(亮度, 16/255, 64/255) ** 0.85`。
   这类画的背景就是"压得很暗的烟雾与星点"，亮度天然是一张不错的遮罩：暗部全透明、
   烟雾保留层次、主体（皮肤/布料/毛）保持不透明。
   阈值是实测调过的：`3/64` 一类更松的取值会在页面上显出一块偏亮的矩形（实测素材内
   空背景与画布亮度差 +13.3），`16/64` 收敛到 +6.4 且烟雾仍在。
2. **反预乘（unpremultiply）**：JPEG 是"压在黑底上的合成结果"，把颜色还原成 `c / alpha`，
   半透明像素叠到非纯黑背景上才不会发灰。
3. **边缘衰减烘焙进 alpha**：右 14% / 左 5% / 上 3% 用 smoothstep 收到 0。
   这一步必须做在素材里而不是 CSS 里——CSS 渐隐在到达 box 边界前仍留有可观不透明度，
   而素材右缘恰好还有较亮的烟雾与星点，结果会在内容列右边界留下一条可见竖缝。

产物：WebP 约 466 KB（上线用）、PNG 约 1.5 MB（兜底/交付用）。

## 5. 页面侧的配合

- `.hero-art img` 只保留两层 CSS 遮罩：纵向 `#000 40% → transparent 92%`（藏住半身像的
  硬切底边）、横向 `transparent 0% → #000 12%`（左缘轻收口，压太狠会吃掉烟雾）。
  右缘/顶部的收口已在素材里，不要再加 CSS 渐隐，否则双重衰减。
- 换图时保持第 2、3 节的尺寸与构图约定即可；若主体位置变了，同步调 `object-position`
  的横向锚点（当前 58%）。
