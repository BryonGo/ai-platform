# 后宫前台功能清单与最小调整基线

日期：2026-09-12。状态：已撤销的早期草稿，不是用户确认的实施基线。

本文产生于助手误把讨论理解为实施的阶段。下文保留作历史记录，其中“三个主入口”“只挪位置”“本轮已连接”等不得用于指导新设计或认定验收完成。当前首页讨论以 [首页设计说明](./design/hougong-homepage-spec-2026-09-12.md) 为准。用户明确要求后才可修改页面代码。

## 产品定位与范围

面向个人创作者的 AI 图片、视频生产平台。聊天创作降低操作成本，全部效果提供明确的结果入口，角色作为可积累、更新、复用的生产资产。专业画布后续接入，分镜本阶段不展开。

本轮沿用现有功能与 API，只调整导航、页面归属和入口参数。不迁移数据库，不删除旧路由，不重写 create.vue 的生成、计费、任务和会话逻辑。

## 功能归属

| 前台位置 | 现有代码/路由 | 本轮处理 |
| --- | --- | --- |
| 创作：图片 | /create | 保留文生图；图生图仍在图片模式中，依赖现有云端模型与参考图能力 |
| 创作：视频 | /create | 保留首帧图生视频、时长、尺寸与模型选择 |
| 全部效果 | /effects（新增入口页） | 图片/视频分类、名称搜索；首批连接现有图片创作和首帧视频，不新建执行接口 |
| 我的资产：素材 | /assets | 保留素材查询、隐藏、删除、下载、导出 |
| 我的资产：角色 | /characters 及其子路由 | 保留建立、查看和编辑，调整为角色资产语义 |
| 我的资产：作品 | /works 及其子路由 | 保留作品管理及继续创作入口 |
| 历史故事 | /stories 及其子路由 | 从主导航移至账户菜单，保留全部旧功能和链接 |
| 模型 | /models | 从主导航移至账户菜单；创作内的模型选择器保留 |
| 钱包、通知、登录 | /wallet、/notifications、/auth/* | 保留顶栏与账户入口 |
| 原首页 | / | 保留原快速创作及作品入口，更新产品定位文案 |

资产暂沿用现有素材/角色/作品三个页面，通过共享二级导航组织，不合并数据结构。

## 最小管线

1. 用户从创作入口进入，或在全部效果选择图片创作/首帧图生视频。
2. 效果入口仅传 mode=image/video，进入同一个 /create 页面，不预选或暗中切换平台。
3. 用户沿用现有选择器选择模型/平台，输入描述，按能力上传参考图或选择首帧，查看当前费用。
4. 沿用 getCatalog、createTask、任务事件/轮询及产物处理逻辑。
5. 通过原有素材、作品接口查看结果，作品的继续创作入口保持有效。

入口跳转不创建任务、不扣费。文生图和图生图共享图片模式；当前本地底模不接收参考图，不将该能力误标为已支持。费用、默认模型和切换规则本轮不改变；统一报价和显式平台选择的完整体验后续单独核对。

## 全部效果目标与现状

参考 All Effects 的功能组织：工具/预设卡片、示例、分类与搜索、素材输入、少量选项、平台与费用、结果展示。

- 本轮已连接：图片创作、首帧图生视频，操作在原聊天创作页完成。
- 待核对接线：图片编辑的独立效果入口、背景/服饰替换、非色情图片与视频换脸、高清增强、动作/表情/运镜预设、文生视频。
- 待补体验：真实效果示例预览、收藏/热门/最新、专用效果操作页、产物直接转效果或保存为角色。
- 未验证执行能力的项目只列入文档，不发布可生成卡片，也不将通用提示词包装成已实现的专用工具。

## 后续接口边界

后宫和 gamelora 目标为共用后台：账号、资产、任务、模型目录、计费、通知、导出复用；产品导航、效果目录、预设和差异功能按产品扩展。ComfyUI 和云端 API 均通过现有目录/任务能力接入。

用户决定平台，后端负责校验、报价、执行；未来画布复用同一提交与产物管线。此次不建立新插件框架、不选型画布库、不增加虚假的工作台入口。

## 验收与已知限制

- 桌面与移动端主导航均为三个入口，角色/作品详情仍归属我的资产。
- 效果分类、搜索、无结果状态可用；图片/视频入口进入正确模式。
- 原角色、故事、作品、模型、钱包路由保持可访问。
- 运行类型检查、构建与受影响文件 lint，记录失败是否来自现有代码。
- 真实生成需要可用后台、账号和额度；前端静态/浏览器验证不能替代付费生成验证。
